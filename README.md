# HR Employee Attrition Analysis

SQL-based analysis of employee workforce, salary, job roles, and attrition patterns using PostgreSQL.

## Objective

To analyze employee data and identify workforce and attrition trends that can support employee retention and workforce management decisions.

## Key Analysis

- Workforce overview and departmental distribution
- Salary and job role analysis
- Employee attrition analysis
- Attrition by department and overtime
- Employee salary ranking
- Employee, manager, and location analysis using JOINs

## Key Insights

- Total workforce: 1,470 employees
- Overall attrition rate: 16.12%
- Sales has the highest attrition rate: 20.63%
- Overtime employees have a higher attrition rate: 30.53%

## SQL Concepts Used

- Aggregate Functions
- GROUP BY & HAVING
- Subqueries
- CTEs
- JOINs
- Window Functions
- RANK() & DENSE_RANK()

## Project Files

- `HR_Employee_Attrition.sql`
- `HR-Employee-Attrition.csv`
- `Department.csv`

## Recommendations

- Focus retention efforts on departments with higher attrition.
- Review overtime workload and employee support.
- Consider compensation and career-growth opportunities.

## Conclusion

The analysis provides insights into employee attrition and workforce patterns that can help support data-driven HR decisions.
